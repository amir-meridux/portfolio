## Featured Case Studies

### 1. Meridux PatientCore - A Clinical Intelligence System

**What it is:** AI-powered patient intake and triage automation platform.

**What it does:**
- Automatically processes incoming patient enquiries via form submission
- Detects duplicate submissions in real-time (race condition protection)
- Routes patients to the right department/doctor based on symptoms
- Flags high-priority cases for immediate attention
- Sends automated confirmation emails within 30 seconds
- Logs all encounters with audit trail
- Generates daily executive summary reports

**Tech Stack:**
- n8n (workflow automation)
- Tally Forms (patient intake)
- Google Sheets (data storage)
- Gmail API (email notifications)
- Pinecone (vector database)
- JavaScript (custom logic)

**Key Features:**
- 10-stage fully automated pipeline
- Zero manual data entry
- Duplicate prevention via intelligent locking mechanism
- Conditional routing (new/returning/ineligible patients)
- Sub-30-second processing time
- Complete audit trail logging
- Daily automated reporting

**Results:**
- Reduces manual intake workload by 10–20+ hours per week
- Eliminates duplicate record creation
- Improves patient experience with instant confirmations
- Provides real-time visibility into clinic operations
